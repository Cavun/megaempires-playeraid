Phase 9 Tool

Calamity Resolution

← Phase Order
In 12–18 player games the civilizations are split into two blocks — West (AST 1–17, odd) and East (AST 2–18, even). For each calamity, set who holds it (the primary victim), then choose a beneficiary and/or secondary victims. This tool applies the large-game rules automatically:
  • For a Non-Tradeable calamity, the beneficiary and secondary victims must come from the same block as the primary victim.
  • For a Tradeable calamity, either block is fair game. Tradeable status is fixed per calamity, so it's set automatically when you pick a name.
  • A civ can't be picked as a secondary victim of a calamity if it's already the primary victim, a secondary victim, or the beneficiary of another calamity with the same name this turn.
  • For board-area calamities (Volcanic Eruption, Flood, Barbarian Hordes, Cyclone) actual victims depend on token positions rather than a free choice — use the "Area effect" flag to relax the block rule.
  • Minor calamities aren't used in 12–14 player games — this tool hides them from the picker automatically based on how many civs are currently marked "in game" below, and shows them again for 15–18 player games.
See the rulebook (p.24) for the full 12–18 player rules — Mega Empires: The East rulebook ↗.
